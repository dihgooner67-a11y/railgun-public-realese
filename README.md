# Rail Gun / Void Eclipse / Azure Flame Glove (Fabric 1.21.1)
- Rail Gun: hold right-click ~1s, release. Costs iron ingots (free in creative). 3D model with 4 glow stages.
  Beam tunnels through up to 4 blocks (hardness <= 20) leaving craters; drops items.
- Azure Flame Glove: hold it in either hand and punch. Blue-flame hit, 10% chance of a Black Flash
  (4x damage, huge knockback, red-lightning impact frames).
- Void Eclipse: right-click. Builds a bedrock/sea-lantern sphere (radius 10) around you with a black & white
  checkerboard floor, holds ~8s, then restores every original block. 2 min cooldown.
  (Blocks with inventories are never touched. If the server crashes mid-spell, blocks stay changed.)
